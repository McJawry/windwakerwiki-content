# Wiki content

These are the pages of the wiki. Editors can change anything here, but this repository contains no code,
so the worst a mistake can do is change a page (and every change can be undone from the history).

- Pages are Markdown files. Use the wiki's editor instead of editing files by hand.
- `_index.json` is generated automatically by the *Update page index* workflow. Don't edit it.
- Give editors **Write** access under **Settings → Collaborators**.
